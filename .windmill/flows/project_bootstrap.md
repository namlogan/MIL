# wm_project_bootstrap

Purpose: create the reusable project framework pack before implementation work.

Steps:
- Copy project intake templates.
- Register Delivery OS documents and checklists.
- Register contract-first folders.
- Configure product CI profile as disabled or enabled with explicit stack.
- Configure release gate and rollback checklist.
- Configure scoped Memory0 namespace and memory policy.
- Record bootstrap evidence in `.ai-factory/qa/`.

This flow may prepare files and evidence, but it must not dispatch coding work.
