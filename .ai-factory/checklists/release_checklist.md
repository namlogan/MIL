# Release Checklist

Use this before promoting a release candidate beyond development.

- [ ] Release manifest exists.
- [ ] Linked issues and PRs are listed.
- [ ] Artifact versions and config diff are recorded.
- [ ] Migration plan and rollback command are present.
- [ ] Local, CI, product CI, and contract checks passed.
- [ ] Staging smoke evidence is attached.
- [ ] Shadow or read-only observation is complete when applicable.
- [ ] Monitoring and alert owners are named.
- [ ] Product owner approval is recorded.
- [ ] Release memory writeback creates only reviewable candidates.
