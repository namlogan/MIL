# Project Intake Checklist

Use this checklist before the first agent-runnable task in a new project.

- [ ] Project brief is written and linked.
- [ ] Business objective and success metrics are explicit.
- [ ] Target users, workflows, and MVP scope are documented.
- [ ] Out-of-scope items are documented.
- [ ] Security, compliance, data, and credential risks are recorded.
- [ ] Deployment target and environment assumptions are stated.
- [ ] Open questions have owners.
- [ ] Risk register exists.
- [ ] Decision owner is named.
- [ ] Project docs pass `scripts/project-intake/validate_project_intake.py`.
- [ ] Delivery OS and contract validators pass.
