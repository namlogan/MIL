# PR Review Checklist

Use this for Codex QA and merge-controller review.

- [ ] One task, one branch, one PR.
- [ ] PR references the issue and acceptance criteria.
- [ ] Diff is inside allowed files.
- [ ] Handoff includes files changed, rules, tests, risks, and rollback.
- [ ] Required contract, product, security, and memory gates ran.
- [ ] Test evidence is attached or linked.
- [ ] Restricted changes are declared.
- [ ] PR size is under 300 LOC preferred, or split/approval evidence exists.
- [ ] Memory candidate is sanitized and sourced, or not applicable.
- [ ] Final gate decision is one of the allowed values.
