# Task Ready Checklist

Use this before Windmill dispatches a coding worker.

- [ ] Task ID and source issue are present.
- [ ] Business reason and acceptance criteria are checkable.
- [ ] Source references are linked.
- [ ] Allowed files and restricted areas are explicit.
- [ ] Expected tests and quality gates are selected.
- [ ] Dependencies and blockers are listed.
- [ ] Rollback impact is stated.
- [ ] Memory preflight scope is recorded.
- [ ] Augment context need is stated when codebase navigation is useful.
- [ ] Handoff format is known.
- [ ] `wm_definition_of_ready_check` returns ready.
