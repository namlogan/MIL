# Rollback Checklist

Use this for production or production-like changes.

- [ ] Rollback command or procedure is explicit.
- [ ] Rollback owner is named.
- [ ] Rollback data impact is documented.
- [ ] Migration rollback or forward-fix decision is stated.
- [ ] Feature flag or config rollback is documented when applicable.
- [ ] Smoke test after rollback is defined.
- [ ] Monitoring signal for rollback success is defined.
- [ ] Manual steps are minimized and owned.
- [ ] The rollback drill result is attached to the release evidence.
