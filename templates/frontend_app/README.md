# Frontend App Template

Baseline for a frontend application.

Include:
- App shell with health or status view.
- API client generated or checked against `contracts/api/openapi.yaml`.
- Component tests and e2e smoke path.
- Accessibility and responsive layout checks.
- Environment config through public-safe variables only.
- Build command and deploy preview command.

Feature work must start from user flows and acceptance criteria, not from a
marketing landing page unless the project explicitly requires one.
