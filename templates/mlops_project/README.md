# MLOps Project Template

Baseline for projects with datasets, models, or evaluation loops.

Include:
- Dataset registry or DVC/object-store reference.
- Model artifact registry reference.
- Training and evaluation commands.
- Promotion criteria.
- Bias, safety, or quality notes where relevant.
- Rollback to prior model version.
- Experiment and metric evidence.

Memory may store lessons about model operations, but not raw datasets or model
weights.
