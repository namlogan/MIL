# Open Questions

## Purpose

Open questions are tracked here so agents do not turn assumptions into
requirements. A question becomes source-of-truth only after the owner resolves
it in docs, issue, ADR, or PR.

## Priority Values

Use Critical, Important, or Later. Critical questions block bootstrap or agent
dispatch. Important questions block release if unresolved. Later questions stay
visible but do not block the next SDLC gate.
